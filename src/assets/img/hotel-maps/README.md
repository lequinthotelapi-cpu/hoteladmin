# Hotel Maps - SVG Files

Esta carpeta contiene los mapas SVG de la distribución del hotel por piso.

## Archivos

- `floor-1.svg` - Mapa del primer piso
- `floor-2.svg` - Mapa del segundo piso

## Uso

Los mapas se muestran en el módulo de Habitaciones cuando se selecciona "Vista Mapa".

## Formato

- Formato: SVG
- Recomendación: Mantener proporciones consistentes entre pisos
- Los SVGs deben ser responsive y escalables
