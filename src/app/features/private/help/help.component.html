Ayuda - Sistema de Gestión Hotelera

Guía de flujos operativos y módulos disponibles

timeline Flujos Operativos del Sistema

event Flujo de Reservas y Estadía

1
Crear Reserva

Módulo: Reservas → Seleccionar habitación, fechas, huésped y confirmar disponibilidad

2
Check-in

Módulo: Recepción → Habitación cambia a "Ocupada", se crea cuenta (folio) automáticamente con cargo de alojamiento

3
Gestión de Cuenta

Módulo: Cuentas → Agregar cargos (servicios, minibar, etc.) y registrar pagos durante la estadía

4
Check-out

Módulo: Recepción → Habitación cambia a "Sucia", cerrar cuenta cuando balance = 0

cleaning_services Flujo de Limpieza (Housekeeping)

1
Asignar Tarea

Módulo: Housekeeping → Crear tarea, asignar empleado, tipo y prioridad. Habitación cambia a "En Limpieza"

2
Completar Tarea

Módulo: Housekeeping o Habitaciones → Registrar duración, notas y marcar si requiere mantenimiento

3
Habitación Disponible

Módulo: Habitaciones → Al completar, habitación cambia a "Disponible" (o "Mantenimiento" si se marcó)

account_balance_wallet Flujo Financiero

1
Abrir Caja

Módulo: Caja → Registrar monto inicial para comenzar operaciones del día

2
Registrar Ventas

Módulo: POS → Venta directa (requiere caja abierta) o cargar a habitación (sin caja)

3
Registrar Pagos

Módulo: Cuentas → Aplicar pagos a folios de huéspedes (efectivo, tarjeta, transferencia)

4
Generar Factura

Módulo: Facturas → Solo si cuenta cerrada y balance = 0. Genera PDF e imprime

5
Cerrar Caja

Módulo: Caja → Cuadrar efectivo, registrar diferencias y cerrar turno

inventory_2 Flujo de Inventario

1
Crear Producto

Módulo: Productos → Definir nombre, categoría, precio y stock inicial

2
Ajustar Stock

Módulo: Inventario → Registrar entradas (compras) o salidas (mermas, consumo interno)

3
Venta Automática

Módulo: POS → Al vender, el stock se reduce automáticamente

assessment Flujo de Análisis y Reportes

1
Dashboard Financiero

Módulo: Reportes → Ver KPIs: Ingresos, Ocupación, RevPAR, ADR, Por Cobrar, Efectivo en Caja

2
Filtrar Período

Módulo: Reportes → Seleccionar rango de fechas (Hoy, Semana, Mes, Año, Personalizado)

3
Analizar Gráficos

Módulo: Reportes → Ingresos por día (línea) e Ingresos por fuente (pastel)

 info Información General

Sistema de Gestión Hotelera - Le Quint Hotel

Sistema completo de administración hotelera con módulos integrados para operaciones, finanzas, inventario y administración.

Características Principales:

  • Gestión de Reservas: Control completo de bookings con prevención de overbooking
  • Check-in/Check-out: Proceso automatizado con generación de folios
  • Housekeeping: Asignación y seguimiento de tareas de limpieza
  • POS Integrado: Punto de venta con carga a habitación
  • Facturación: Generación de facturas con PDF e impresión directa
  • Reportes Financieros: KPIs hoteleros (RevPAR, ADR, Ocupación)
  • Control de Inventario: Gestión de stock y movimientos
  • Notificaciones: Sistema en tiempo real con Firestore
  • Permisos por Rol: Control de acceso granular

Soporte:

Para asistencia técnica o consultas, contacta al administrador del sistema.
